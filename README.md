## 📖 معرفی برنامه (Introduction)

**ایلرن‌یار (ElearnYar)** یک اپلیکیشن اندروید است که برای دانشجویان دانشگاه شهید باهنر کرمان طراحی شده تا فرآیند پیگیری دروس، فایل‌های آموزشی و به‌ویژه مهلت تحویل تمرین‌های سامانه آموزش مجازی (`elearn.uk.ac.ir`) را به ساده‌ترین و دقیق‌ترین شکل ممکن مدیریت کند.

این برنامه بدون نیاز به ورود مداوم به سایت، به صورت خودکار دوره‌های تحصیلی و دروس هر ترم دانشجو را به تفکیک شناسایی کرده و فایل‌ها و تکالیف جدید را پایش و یادآوری می‌کند.

---

## ✨ ویژگی‌های کلیدی (Key Features)

### 🔔 سیستم یادآور و نوتیفیکیشن هوشمند (Smart Notification System)
- **پایش خودکار دوره‌ای:** پایش در بازه‌های زمانی دلخواه (هر ۱، ۲، ۳، ۶، ۱۲ یا ۲۴ ساعت).
- **هشدار چندمرحله‌ای برای تکالیف:**
  - با هر بار پایش برنامه
  - یک هفته قبل از پایان مهلت
  - روز موعود تحویل
  - ۳ ساعت قبل از پایان زمان
  - ۱ ساعت قبل
  - ۱۵ دقیقه قبل
- **شخصی‌سازی اعلان‌ها:** امکان فعال یا غیرفعال کردن هر کدام از زمان‌های یادآوری به صورت مستقل.

### 📚 مدیریت تفکیک‌شده دروس و تکالیف (Courses & Assignments)
- **بخش فایل‌های آموزشی:** منوی کشویی آکاردئونی برای هر درس با نمایش تاریخ بارگذاری و جزئیات استاد.
- **بخش تمرین‌های فعال:** نمایش کارت‌های تمرین دارای مهلت به همراه شمارشگر معکوس و تاریخ شمسی دقیق.
- **منوی کشویی تمرین‌های منسوخ‌شده:** انتقال منظم تمرین‌های پایان‌یافته به انتهای لیست در منوی تاشو خاکستری-سورمه‌ای.

### 📥 دانلود و آپلود پیشرفته فایل‌ها (File Management)
- **دانلود مستقیم در پوشه عمومی Downloads گوشی:** سازگار با معماری Scoped Storage در اندروید ۱۰ تا ۱۴ از طریق `MediaStore.Downloads`.
- **بررسی هوشمند فایل‌های تکراری:** در صورت وجود قبلی فایل، از کاربر سوال می‌شود که آیا مایل به باز کردن فایل موجود است یا دانلود مجدد.
- **باز کردن سریع فایل پس از دانلود:** نمایش پاپ‌آپ و اسنک‌بار اختصاصی روی صفحه جهت باز کردن آنی فایل‌های دریافتی (PDF، جزوه‌ها و...).
- **آپلود پاسخ تمرین‌ها:** قابلیت ارسال مستقیم فایل پاسخ تکالیف به همراه توضیحات از داخل برنامه.

### 🎨 رابط کاربری شیشه‌ای و مدرن (Glassmorphism & Theming)
- **تم اختصاصی Glassmorphism:** طراحی شیشه‌ای شیک با گوشه‌های گرد و کادرهای شفاف.
- **تم دارک شیک (Dark Navy):** پس‌زمینه سورمه‌ای عمیق (`#0B132B` و `#131F3B`) با لهجه‌های فیروزه‌ای (`#38BDF8`).
- **تم لایت (Light Mode) و پیرو سیستم (Follow System):** هماهنگ با حالت تاریک/روشن گوشی.
- **تقویم شمسی دقیق:** تبدیل دقیق تاریخ میلادی به تاریخ خورشیدی با الگوریتم نجومی استاندارد JDF.

## 🔒 امنیت و حریم خصوصی (Privacy & Security)

- تمامی اطلاعات لاگین (نام کاربری و رمز عبور) **تنها روی حافظه داخلی خصوصی گوشی خود شما** ذخیره شده و مستقیماً با پروتکل HTTPS به سرور دانشگاه (`https://elearn.uk.ac.ir`) متصل می‌شود.
- **هیچ‌گونه سرور واسط یا شخص ثالثی وجود ندارد** و تمام عملیات به صورت Client-Side و محلی انجام می‌پذیرد.

## 🛠 معماری و تکنولوژی‌ها (Tech Stack)

| بخش | تکنولوژی |
| :--- | :--- |
| **زبان توسعه** | Java (Android Native) |
| **حداقل نسخه اندروید** | Android 5.0 (API 21) |

## 🚀 راهنمای بیلد و اجرا (Build & Setup)

برای دریافت و بیلد پروژه با Android Studio یا خط فرمان:

```bash
# 1. کلون کردن ریپازیتوری
git clone https://github.com/Seyyedaliit/elearnyar.git
cd elearnyar

# 2. بیلد نسخه دیباگ با گریدل
# در لینوکس یا مک:
./gradlew assembleDebug

# در ویندوز:
.\gradlew.bat assembleDebug
```

فایل APK خروجی در مسیر زیر ایجاد می‌شود:
`app/build/outputs/apk/debug/app-debug.apk`

## 🍏 وب‌اپلیکیشن مخصوص آیفون (iOS Web App / PWA)

برای کاربران سیستم‌عامل **iOS (آیفون و آیپد)** و مرورگرهای دسکتاپ، نسخه کامل وب‌اپلیکیشن در پوشه `webapp/` قرار دارد:
- پشتیبانی کامل از **Add to Home Screen** در Safari آیفون (اجرای تمام‌صفحه و بدون نوار آدرس).
- پشتیبانی از تمام ۴ تب: تمرین‌های فعال، فایل‌های آموزشی، پیام‌های اساتید و سوابق حضور و غیاب.
- طراحی اختصاصی شیشه‌ای منطبق با ابعاد آیفون و جزیره پویا (Dynamic Island).
- راهنمای کامل اجرا در [webapp/README.md](webapp/README.md) در دسترس است.
